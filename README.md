# Macao Lee 중국어

완전 초보를 위한 중국어 연습 게임. 파일 하나로 돌아가는 정적 사이트입니다.

- **소리 익히기** 4단원 — 성조 네 가지, 성모, 운모, 헷갈리는 소리와 성조 변화
- **말하기 다지기** 12단원 — 인사·숫자·가족·하루 일과·음식 주문·쇼핑·길·숙소·병원·날씨·전화·여행
- **문법 익히기** 8단원 — 是자문과 有자문, 양사, 의문문, 비교, 了/过/着, 조동사, 把자문, 보어
- 간체자 576개 · 문장 160개 · 레슨 120개, 세 트랙은 서로 독립적으로 열립니다
- 문제 유형: 뜻 고르기 / 중국어 고르기 / 병음 고르기 / 듣기 / 병음 입력 / 짝 맞추기 / 문장 배열
- 병음 입력은 관대합니다 — `nǐ hǎo` · `ni3 hao3` · `nihao` 모두 정답
- 라이트너 방식 간격 반복 복습, 진행 상황 백업 코드, 계정 로그인 시 기기 간 진도 동기화

`index.html` 하나가 전부입니다. 빌드 과정이 없습니다.
